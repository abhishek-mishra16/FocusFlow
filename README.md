# FocusFlow Premium

A responsive productivity dashboard built with React, TypeScript, Vite, Framer Motion, Three.js, and dnd-kit.

## Features
- Responsive desktop and mobile layout
- Tasks with add, delete, complete, status cycling, filtering, search, and drag-and-drop
- Goals and milestone tracking
- Habit tracker with weekly streaks
- Weekly calendar
- Analytics and achievements
- Pomodoro/focus timer
- Premium visual themes and dark/light mode
- Local browser persistence with localStorage
- Animated 3D focus crystal

## Run locally

```bash
npm install
npm run dev
```

For a LAN/mobile preview:

```bash
npm run dev -- --host
```

## Production build

```bash
npm run build
npm run preview
```
