# ✦ FocusFlow

### A premium, responsive productivity dashboard designed to help you focus, plan, and build better habits.

FocusFlow is a modern productivity web application that brings **tasks, goals, habits, focus sessions, analytics, and achievements** together in one interactive dashboard.

It combines a clean glassmorphism-inspired interface with subtle animations, responsive layouts, customizable themes, and persistent local data to create a focused productivity experience across **desktop and mobile devices**.

---

## ✨ Features

### 📋 Smart Task Management

* Create and delete tasks
* Mark tasks as completed
* Move tasks between:

  * To Do
  * In Progress
  * Done
* Search tasks
* Filter tasks
* Drag & drop task reordering
* Priority indicators
* Due dates and categories

### 🎯 Goals & Milestones

* Create personal goals
* Track goal progress
* Add milestones to goals
* Complete individual milestones
* Visual progress indicators
* Delete completed/unwanted milestones

### 🔥 Habit Tracker

* Create custom habits
* Track habits throughout the week
* Click to mark daily completion.
* Automatic streak tracking.
* Weekly completion visualization.

### ⏱️ Focus Timer

* Pomodoro-style focus sessions
* Multiple session durations
* Start / pause / reset controls
* Visual countdown
* Focus session statistics

### 📅 Weekly Planner

* Interactive weekly calendar
* View scheduled tasks
* Daily productivity overview
* Quick navigation between days

### 📊 Analytics

Track your productivity through:

* Completed tasks
* Active goals
* Habit streaks
* Focus sessions
* Weekly productivity
* Completion rates

### 🏆 Achievements

Unlock productivity milestones as you make progress and maintain consistent habits.

### 🎨 Premium Themes

Choose from multiple visual styles:

* Cosmic Focus
* Sunset Momentum
* Zen Garden
* Ocean Deep
* Aurora Calm
* Cyber Minimal
* Paper + Neon
* Monochrome Pro

Themes can be changed directly from the application.

### 🌗 Dark & Light Mode

Switch between dark and light interfaces depending on your preference.

### 📱 Fully Responsive

FocusFlow is designed to work across:

* 💻 Desktop
* 🖥️ Laptop
* 📱 Mobile
* 📲 Tablet

The layout automatically adapts to different screen sizes.

### 💾 Persistent Data

Tasks, habits, goals, and theme preferences are stored locally using **browser localStorage**, allowing your data to remain available when you return to the application.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/abhishek-mishra16/FocusFlow.git
```

### 2. Enter the project directory

```bash
cd FocusFlow
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Vite will provide a local development URL, typically:

```text
http://localhost:5173
```

Open it in your browser.

---

## 🏗️ Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🎮 How to Use

### Tasks

1. Open the **Tasks** section.
2. Add a new task.
3. Assign a priority/category if needed.
4. Move the task through its workflow.
5. Mark it complete when finished.
6. Reorder tasks using drag & drop.

### Goals

1. Open **Goals**.
2. Create a goal.
3. Add milestones.
4. Complete milestones as you progress.
5. Monitor the goal's progress visually.

### Habits

1. Open **Habits**.
2. Add a habit.
3. Mark each day as completed.
4. Maintain your streak.
5. Use the weekly view to monitor consistency.

### Focus Sessions

1. Open the focus timer.
2. Select your preferred session duration.
3. Start the timer.
4. Work without distractions.
5. Track your completed focus sessions.

## 🎨 Design Philosophy

FocusFlow was designed around a simple idea:

> **Productivity should feel motivating, not overwhelming.**

The interface uses:

* Glass-style cards
* Soft gradients
* Micro-interactions
* Animated transitions
* Responsive layouts
* Visual progress indicators
* 3D decorative elements
* Minimal navigation

The goal is to make productivity information easy to understand at a glance while keeping the interface visually engaging.

---

## 🔒 Data & Privacy

FocusFlow currently stores productivity data locally in the browser using `localStorage`.

There is no external database or authentication system required for the current version.

This means your locally stored tasks, goals, habits, and preferences remain within your browser environment.
